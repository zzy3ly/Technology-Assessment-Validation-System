# 反思与评估真实模型实验 v1

日期：2026-10-13。结论：本轮没有观察到正向收益，正确率从 19/24 降至 17/24。

## 协议

24 条固定任务：金额与手续费、最新记录筛选、工具执行事实、Python 代码推演、工作日日期、证据不足与冲突，各 4 条。测试前生成标准答案，禁止根据结果删题。全部任务要求精确 JSON 输出，标准答案由本地程序计算并由审计测试独立核验。字段缺失、多余字段、类型错误或值错误均判不正确，不使用关键词加权分数。

初始答案由真实 DeepSeek 调用生成，没有人工注入错误。随后调用项目现有 ReflectionAgent.process、EvaluationAgent.process。保留现有 Prompt、解析与选择逻辑；以单独、限时的 OpenAI 兼容 SDK transport 调用 DeepSeek，绕过 Agent 初始化时与本实验无关的内存/语音依赖。未测试完整 Planner 路由或生产 Provider 的重试逻辑。

初始、反思、评估三个阶段得到相同用户要求及题目证据，均看不到 expected 字段。所有模型调用使用 deepseek-chat、temperature=0、max_tokens=1800；仍不能保证跨时间完全可重复。每题另做一次候选位置交换的评估，仅作诊断，不用于事后选择更有利的最终答案。

总计 96 次真实 API 请求（初稿24、反思24、评估24、交换位置评估24），43,247 tokens，零接口错误、零长度截断。首条冒烟测试的4次结果被后续运行复用，不重复付费。每次调用保存请求消息、返回模型名、原文、用量、耗时和完成原因；未保存凭据。文件内 usage 用于核验，不以缺省 cost=0 推断免费。

## 指标与结果

| 阶段 | 正确数 | 正确率 |
|---|---:|---:|
| 初始答案 | 19/24 | 79.17% |
| 反思后答案 | 17/24 | 70.83% |
| 评估选择后的最终答案 | 17/24 | 70.83% |

反思后及完整反思评估链路相对初稿均下降 8.33 个百分点，故 A=-8.33。

胜负由独立正确性判分：初稿错误→修订正确才为胜；初稿正确→修订错误为负；同对或同错为平，不把模型自评分升高作为胜出。

- 胜0、负2、平22；以全部24条为分母，修订胜率 B=0%。
- 仅看非平局，胜率也为0/2；样本很小，不能据此推广总体比例。
- 初稿错误的5条，反思纠正0条。
- 初稿正确的19条，反思损坏2条，原正确答案退化率10.53%。
- 两条一对一错的候选中，原顺序评估选对0/2，交换顺序选对1/2。这个数量不足以估计普遍的位置偏差，但说明当前选择不稳定。

## 已核实的失败机制

business_days-1、business_days-2：从10月10日或11日之后数五个工作日，排除周末和10月12日假日，正确日期为10月19日。初稿正确；反思改为10月16日并给出0.95置信度。

EvaluationAgent 的返回理由列出了13、14、15、16、19五个工作日，文字上承认初稿正确，却仍在结构化字段里给初稿4分、修订9分。运行时代码强制按数值高低选择，导致选错。交换位置后，其中一条仍存在数值与文字矛盾。这证明结构化格式合法不代表判断正确。

代码推演四条均未修好；其中评估理由能够推演出正确结果，但候选仍都错误。现有评估 Agent 只负责选候选，不生成第三个正确答案，因此不能把理由中的正确推演计为任务完成。

## 局限与使用建议

这是单次运行、六类结构化任务的开发集，各类四条有关联，不是线上随机样本，也不代表开放式写作质量或所有 Agent 任务。未做多次独立采样，不宣称统计显著性。相同模型用于生成、反思和评估可能保留相关错误。不能将本轮负收益推广为“反思永远无用”，但目前没有证据支持在简历中填写正向 A、B。

建议下一轮改进先依据问题而不是成绩：可执行计算接入确定性验证；检测评分字段和选择结论矛盾；无外部证据的推翻应谨慎。改动后建立独立新题集，冻结本轮结果作为基线，避免在这24题上反复调参后宣称泛化收益。本次仅做实验，没有实施这些业务代码变更。
